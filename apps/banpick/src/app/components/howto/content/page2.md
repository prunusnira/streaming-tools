# 1단계: 참여하기

## 스트리머

1. 시작 전에 전체 픽 개수, 턴당 팀별 픽 개수, 스트리머의 밴 개수를 정해.

   ![페이즈 설정 예시](/img/p2st1.png)

   각 턴을 **페이즈**라고 해.

2. 준비가 끝나면 왼쪽 상단의 **인원 모집 시작** 버튼을 눌러 시청자를 받아.
3. 모집을 중단하거나 재개하려면 각각 **인원 모집 중단**, **인원 모집 재개** 버튼을 선택해.

   ![모집 상태 버튼 예시 1](/img/p2st2.png)
   ![모집 상태 버튼 예시 2](/img/p2st21.png)
   ![모집 상태 버튼 예시 3](/img/p2st22.png)

4. 인원 모집 상태와 관계없이 밴픽은 진행할 수 있어.

## 시청자

스트리머가 인원 모집을 시작하면 `!team 1` 또는 `!team 2` / `!팀 1` 또는 `!팀 2`를 채팅에 입력해 두 팀 중 한 곳에 참여해.

![팀 참가 채팅 예시](/img/p2st3.png)
