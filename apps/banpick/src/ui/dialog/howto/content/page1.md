# Twitch BanPicker는?

- 시청자들의 참여를 유도해 콘텐츠에 집중할 수 있게 해주는 트위치 스트리머용 도구야.
- MOBA 장르의 밴/픽과 유사하게 동작해.
- 스트리머가 정한 주제에 따라 시청자에게 선택지나 의견을 받을 수 있어.

# 화면 설명

![Twitch BanPicker 화면 구성](/img/howto.png)

1. **스트리머 조작 컨트롤**
   - 인원 모집 컨트롤: 시청자의 참여 가능 여부를 조절해.
   - 리셋: 현재 시청자 참여 상태와 밴픽 진행 상황을 초기화해.
   - 팀원 목록 표시: 팀원 목록과 인원수 표시 여부를 결정해.
   - 페이즈 컨트롤: 페이즈별 픽·밴 수를 조절해.
   - 현재 페이즈 알림: 현재 상태를 표시하고 강제로 변경할 수 있어.
2. **시스템 메뉴**
   - 사용방법: 현재 보고 있는 창이야.
   - 데이터 리셋: 저장된 트위치 로그인 정보를 초기화해.
3. **페이지 표시 컨트롤**
   - 표시할 목록 종류를 선택해.
   - 기본은 유저 목록이며, 밴픽 목록 버튼으로 전환할 수 있어.
4. **플레이 진행 컨트롤**
   - 이 팀에서 선택: 현재 팀의 시청자 중 한 명을 뽑아.
   - 팀명 변경: 선택한 팀의 이름을 변경해.
5. **콘텐츠 표시 영역**: 선택한 목록에 따라 데이터를 보여줘.
6. **트위치 채팅**: 현재 채널의 실시간 채팅을 표시해.
