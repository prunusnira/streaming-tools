# 2단계: 밴픽 진행하기

## 스트리머

1. 인원 모집이 충분하면 **이 팀에서 1명 선택** 버튼으로 각 팀의 시청자 중 한 명을 선택해.
2. 잠시 후 무작위로 사용자가 선택되며, 시청자와 대화하면서 밴픽을 진행할 수 있어.
3. 각 페이즈의 팀별 픽 개수를 모두 채우면 밴을 진행해.
4. 전체 밴픽 과정이 끝날 때까지 반복해.

## 리셋

- 왼쪽 상단의 **리셋** 버튼은 현재 밴픽 진행 상황을 초기화하고 처음 상태로 되돌려.
- 오른쪽 상단의 **데이터 리셋** 버튼은 저장된 스트리머 정보를 지우므로 로그인을 다시 진행해야 해.

## 픽 이후 변경

![픽 이후 조작 버튼](/img/p3st1.png)

픽된 항목에서는 아래 기능을 사용할 수 있어.

- **수정**: 픽된 내용을 바꿔.
- **삭제**: 픽 내용을 삭제해. 현재 픽 개수도 차감되므로 다시 픽해야 해.
- **협상**: 해당 픽을 고른 시청자를 다시 불러와 협상할 수 있어.
- **밴/언밴**: 밴 페이즈에서 해당 항목을 밴 처리하거나 되돌려.
